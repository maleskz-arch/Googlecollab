02

Теория за 10 минут

Три инструмента решают три разные задачи, но вместе образуют рабочее окружение аналитика:

Среда

Jupyter Notebook

Интерактивный блокнот в браузере: код, текст и графики в одном документе. Стандарт для анализа данных и обучения.

Доставка

Docker

Контейнер — «упакованная» система с уже установленным Jupyter и библиотеками. У всех студентов одинаковое окружение одной командой.

Облако

Google Colab

Тот же Jupyter, но на серверах Google: ничего устанавливать не нужно, работает даже на слабом ноутбуке, легко делиться ссылкой.

Зачем Docker, если есть Colab?

Colab требует интернет и аккаунт Google, а сессия ограничена по времени. Docker работает локально: данные не покидают компьютер, окружение воспроизводимо буквально до версии библиотек, и его можно запустить на сервере университета или компании.

Правило простое: быстрый старт и совместная работа — Colab; воспроизводимость и контроль — Docker. Профессионал владеет обоими.

Что такое «образ» и «контейнер» простыми словами?

Образ (image) — это шаблон, как установочный диск: в нём уже записаны Linux, Python, Jupyter и нужные библиотеки. Мы используем готовый образ jupyter/datascience-notebook.

Контейнер (container) — запущенная копия образа. Из одного образа можно поднять хоть десять контейнеров, и каждый будет изолирован от системы: удалил контейнер — и следов не осталось.

Важно: Google Colab не использует Docker на вашей стороне — контейнеры крутятся внутри инфраструктуры Google. Docker в этом занятии — ваш локальный, полностью контролируемый путь к тому же Jupyter.

03

Практика А: Jupyter Notebook в Docker

Понадобится установленный Docker Desktop (Windows/macOS) или Docker Engine (Linux). Все команды выполняйте в терминале: PowerShell на Windows, Terminal на macOS/Linux.

1

Проверьте, что Docker работает

Если видите номер версии — всё готово. Если ошибку — Docker Desktop нужно запустить (или установить).

терминал
$ docker --version
# Docker version 27.x.x, build ...
2

Запустите Jupyter одной командой

При первом запуске Docker скачает образ (~2–3 ГБ, один раз). Разберём флаги: --rm — удалить контейнер после остановки, -p 8888:8888 — пробросить порт, -v — подключить текущую папку, чтобы файлы не пропали.

macOS / Linux
$ docker run --rm -p 8888:8888 \
    -v "$(pwd)":/home/jovyan/work \
    jupyter/datascience-notebook
Windows PowerShell
> docker run --rm -p 8888:8888 `
    -v "${PWD}":/home/jovyan/work `
    jupyter/datascience-notebook
3

Откройте Jupyter в браузере

В логах терминала найдите строку вида http://127.0.0.1:8888/lab?token=... и откройте её. Создайте новый блокнот Python 3 и выполните первую ячейку:

ячейка ноутбука
import sys
print("Jupyter работает! Python", sys.version.split()[0])
4

Остановите контейнер правильно

Вернитесь в терминал и нажмите Ctrl+C. Благодаря флагу --rm контейнер удалится сам, а файлы останутся в вашей папке — их спас флаг -v.

Чекпоинт: отметьте пункт «Запустил Jupyter Notebook в Docker» в чек-листе слева. Если токен потерялся — новый виден в логах контейнера после перезапуска.

Мини-проект: кто выживал на «Титанике»?

06

Проверка знаний

Пять вопросов. Ответьте на все и нажмите «Проверить» — обратная связь появится сразу. Для зачёта нужно 4 из 5.

1. Что делает флаг -p 8888:8888 в команде docker run?

Верно! Без проброса порта браузер на вашем компьютере не достучался бы до Jupyter внутри контейнера.
Не совсем. Флаг -p связывает порт вашего компьютера с портом внутри контейнера — именно так браузер попадает в Jupyter.

2. Зачем в команде используется -v "$(pwd)":/home/jovyan/work?

Точно! Это «volume» — общая папка между компьютером и контейнером. Без неё ноутбуки исчезли бы вместе с контейнером.
Нет. Флаг -v монтирует вашу папку внутрь контейнера — файлы из неё переживают удаление контейнера.

3. Чем Google Colab принципиально отличается от запуска Jupyter в Docker?

Именно так. Colab — тот же Jupyter в облаке Google, бесплатный и без установки.
Проверьте раздел «Теория»: Colab — бесплатный Jupyter на серверах Google, установка не нужна, но нужен интернет.

4. Что выведет df.groupby("class")["survived"].mean()?

Верно! Колонка survived содержит 0 и 1, поэтому её среднее — это доля выживших.
Подсказка: survived — это 0 или 1. Среднее таких значений равно доле выживших в группе.

5. Почему один и тот же код работает и в Docker-Jupyter, и в Colab?

Да! Воспроизводимость окружения — главная идея занятия: одинаковые библиотеки → одинаковый результат.
Ключевое слово — окружение: в обоих случаях установлены Python и pandas, поэтому код переносится без изменений.
